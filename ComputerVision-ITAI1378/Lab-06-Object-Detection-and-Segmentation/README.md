# Lab 06: Object Detection and Image Segmentation

## Overview

This project explores object detection and image segmentation using pretrained computer vision models. I worked with YOLO11, YOLO11-seg, and SAM 2 to understand how different models identify objects, locate them in images, and generate segmentation masks.

I tested the models on a desk image containing several everyday objects, compared their outputs, and conducted additional experiments with confidence thresholds, model sizes, and open-vocabulary detection using YOLO-World.

The lab demonstrates how pretrained models can be used for computer vision applications without training a new model from scratch.

## Project Implementation

### 1. Object Detection with YOLO11

I used a pretrained YOLO11 nano model to detect and label objects using bounding boxes and confidence scores.

On my desk image, YOLO11 returned eight detections:

- Laptop
- Two potted plants
- Cup
- Cell phone
- Book
- Vase
- Dining table

The model correctly identified several objects but labeled the notebook as a book, the pen holder as a vase, and the desk as a dining table.

### 2. Confidence Threshold Experiment

I tested three confidence thresholds on the same desk image to compare how the number of detections changed.

| Confidence Threshold | Detections |
|---|---:|
| 0.10 | 12 |
| 0.25 | 8 |
| 0.70 | 4 |

Lower thresholds produced more detections, while higher thresholds removed uncertain predictions.

The highest threshold removed some incorrect labels but also excluded correctly detected objects.

### 3. Image Segmentation with YOLO11-seg

I used YOLO11-seg to generate pixel-level masks instead of only bounding boxes.

On my desk image, the segmentation model produced five masks.

This experiment helped me understand how segmentation provides more detailed object boundaries than standard detection.

### 4. SAM 2 Segmentation

I used the pretrained SAM 2 model with bounding boxes generated by YOLO11 as prompts.

On the same desk image:

| Model | Masks Generated |
|---|---:|
| YOLO11-seg | 5 |
| SAM 2 | 8 |

SAM 2 generated additional masks for objects such as the notebook, pen holder, and desk.

Unlike YOLO11-seg, SAM 2 did not provide category names for the segmented objects.

## Additional Experiments

### Experiment 1: YOLO11 Nano vs. Small

I compared two pretrained YOLO11 variants using identical confidence thresholds and input sizes.

| Model | Detections |
|---|---:|
| YOLO11 Nano | 8 |
| YOLO11 Small | 13 |

The small model produced more detections and increased the phone's confidence score from 70.0% to 91.5%.

However, it still made incorrect classifications, showing that a larger model does not automatically produce better predictions.

### Experiment 2: Open-Vocabulary Detection with YOLO-World

I tested YOLO-World using custom object categories, including notebook, pen, pen holder, and desk.

YOLO-World returned nine detections and successfully identified the pen with 86.3% confidence.

It also labeled the notebook and desk using the requested category names.

However, the pen holder was incorrectly identified as a coffee cup, demonstrating that custom prompts do not eliminate classification errors.

## Results and Key Findings

The experiments demonstrated several important differences between object detection and segmentation:

- Object detection identifies objects and provides bounding boxes and labels.
- Image segmentation provides more detailed object boundaries through masks.
- Confidence thresholds affect the number of predictions returned.
- SAM 2 can generate masks from bounding-box prompts without providing category labels.
- Larger detection models can return additional predictions without necessarily correcting classification mistakes.
- Open-vocabulary detection allows custom text categories but can still produce incorrect labels.

I learned that the most appropriate computer vision model depends on the task, required output, and importance of avoiding missed or incorrect detections.
