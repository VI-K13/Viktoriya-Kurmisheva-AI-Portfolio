# Lab 06: Object Detection and Segmentation Results

This folder contains visualizations from my object detection and image segmentation experiments using pretrained YOLO11, YOLO11-seg, SAM 2, and YOLO-World models.

## Results Included

1. **Confidence Threshold Comparison:** YOLO11 detection results at confidence thresholds of 0.10, 0.25, and 0.70.
2. **Detection vs. Segmentation:** A comparison of bounding boxes and segmentation masks on the same desk image.
3. **YOLO11-seg vs. SAM 2:** A comparison of segmentation masks generated by the two models.
4. **YOLO11 Nano vs. Small:** A comparison of object detections from two model sizes.
5. **YOLO-World Detection:** Results using custom text-based object categories.

## Key Findings

YOLO11 detected eight objects on the desk image at the default confidence threshold. YOLO11-seg produced five segmentation masks, while SAM 2 produced eight using YOLO11 detection boxes as prompts.

The additional experiments showed that model size, confidence thresholds, and custom object categories influence detection results. More detections or masks do not necessarily indicate better accuracy.
