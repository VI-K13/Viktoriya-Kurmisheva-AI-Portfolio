# Lab 03: Image Classification Results

This folder contains visualizations and experimental results from my image classification lab using Support Vector Machines (SVM) and the CIFAR-10 dataset.

## Results Included

1. **Image Preprocessing:** Examples of the original images and their grayscale transformations used to prepare the data for classification.
2. **True vs. Predicted Labels:** Sample test images comparing the model's predictions with their actual labels.
3. **SVM Accuracy Comparison:** A visualization comparing classification accuracy across different kernels, regularization settings, and training dataset sizes.

## Key Findings

The original Linear SVM achieved 54.70% accuracy. In my experiments, the RBF kernel achieved 62.00% accuracy compared with 50.67% for the Linear SVM using the same smaller training sample.

These results demonstrate how model configuration and training dataset size can affect image classification performance.
