# Lab 04: Neural Network Classification Results

This folder contains visualizations from my Chihuahua vs. Muffin image classification workshop using PyTorch and MySkynet.

## Results Included

1. **Training Image Examples:** Sample images of Chihuahuas and muffins from the dataset.
2. **Validation Predictions:** Examples of how the original neural network evaluated validation images.
3. **Experiment Accuracy Comparison:** A bar chart comparing the original model with six parameter experiments.

## Key Findings

The original model achieved 76.67% validation accuracy. Increasing training from 3 to 10 epochs produced the best result of 93.33%.

The experiments showed how learning rate, optimizer selection, network architecture, image size, data augmentation, and training duration can influence neural network performance.
